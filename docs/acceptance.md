## 上线前仍需完成

1. 按 `docs/deployment.md` 切换生产启动入口并安装插件，先保持 observe；这会涉及 Paseo 服务切换，尚未执行。
2. 在手机实际打开“额度保护”，验收布局、用量刷新、账户选择以及通知点击后的目的页面。当前不承诺通知栏原生“一键暂停”。
3. 使用专门的真实 Claude/Codex 测试会话，验收手动暂停、原会话手动继续及子任务停止状态；当前中断测试主要使用 provider 测试替身，不能代替此项。
4. 对正式接入的执行层验证受控阈值触发和失联保护，不故意将真实订阅消耗到阈值；检查部分停止失败的显示及通知。
5. 完成这些验收后启用 enforce 和开机后台服务，再观察持续运行、额度重置与通知重试。

暂停通过中断当前轮次和阻止后续请求实现，不默认杀掉 Claude/Codex 进程。恢复只解除账户限制，用户在原会话继续；不会自动重放旧任务。采样和在途请求存在延迟，阈值不是计费硬上限。

## 界面设置增量验收

新增测试覆盖：调低阈值立即暂停、调高不自动恢复、关闭后停止拦截/中断/通知、重新开启、重启保留设置、多端 revision 冲突、非法阈值不写入、关闭后监控失联仍可继续、设置损坏时恢复保护，以及很低的自定义暂停线可在额度归零后恢复。插件 TypeScript 检查通过。

这是本地接口和执行层测试，手机上的新开关、数字输入及布局尚未实际验收。上一轮手机推送送达确认仍有效，但不代替新界面验收。旧 `.local/release` 为上一轮快照，含界面设置的新候选包位于 `.local/release-settings`；部署时两个服务和插件都应指向同一新候选版本。
